# neuroALLIANCE 2026 poster

**Biopsychosocial and Epigenetic Markers of Heat-Stress and Posttraumatic Outcomes in Emergency Responders**

Paul Ruiz Pinto and colleagues, QUT and collaborating institutions.

[View and download the poster](https://paulyrp.github.io/neuroalliance26/)

The poster is A0 portrait (841 × 1189 mm), prepared in Adobe Illustrator using Aptos, editable vector figures and the approved navy responder background. The PDF and web transcript report nominal interaction-coefficient p-values and exploratory GO enrichment with their qualifications.

## Updating

Replace `site/poster.pdf` and `site/poster-preview.png`, update the transcript in `site/index.html`, and push to `main`. The GitHub Actions workflow publishes the `site` directory to GitHub Pages. The printed QR code points to the stable viewer URL above.

The Illustrator master and working research reports are maintained in the local project workspace.
